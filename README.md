## 📌 About the Repository

This repository contains the **External Practical Report for Business Intelligence and Tools**, documenting the practical implementation of core Business Intelligence concepts using **Tableau**.

The practical focuses on transforming raw datasets into meaningful analytical insights through data preparation, dimensional modelling, calculated measures, interactive visualisations, and multidimensional data analysis.

It demonstrates how structured data modelling and analytical operations contribute to effective business intelligence and data-driven decision-making.

## 🎯 Practical Objectives

- Load and prepare datasets for analytical processing.
- Identify and organise Fact Tables and Dimension Tables.
- Implement a Star Schema data model.
- Configure relationships between fact and dimension tables.
- Create calculated fields and analytical measures.
- Develop meaningful charts and interactive dashboards.
- Perform multidimensional analysis using OLAP operations.

## 📚 Concepts Covered

### 01. Data Loading & Preparation

Importing datasets, examining data types, identifying missing values, and preparing data for analysis.

### 02. Fact & Dimension Tables

Organising data into:

- **Fact Table:** Numerical measures and foreign keys.
- **Dimension Tables:** Descriptive attributes such as Product, Customer, Time and Location.

### 03. Star Schema Modelling

Designing a dimensional data model with a central Fact Table connected to multiple Dimension Tables through appropriate relationships.

### 04. Relationship Configuration

Establishing one-to-many relationships using primary and foreign keys to create an integrated analytical data model.

### 05. Calculated Measures

Creating analytical calculations using Tableau functions such as:

- `SUM()`
- `AVG()`
- `COUNT()`
- `COUNTD()`
- `MIN()` and `MAX()`

### 06. Data Visualisation

Developing charts and dashboards to represent trends, comparisons, distributions and business performance indicators.

### 07. OLAP Operations

| Operation  | Purpose                        |
| ---------- | ------------------------------ |
| Roll-Up    | Summarising detailed data      |
| Drill-Down | Exploring granular information |
| Slice      | Filtering one dimension value  |
| Dice       | Filtering multiple dimensions  |
| Pivot      | Rotating the analytical view   |
